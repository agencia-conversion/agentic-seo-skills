# EEAT

EEAT ajuda a avaliar se uma página demonstra experiência, especialidade, autoridade e confiança para responder a uma busca.

## Como aplicar

Comece pelo que o leitor precisa verificar para confiar na página. Use evidências reais, explique limites e cite referências públicas com anchors descritivos.
