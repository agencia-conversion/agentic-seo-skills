Como obter suas credenciais DataForSEO

Siga os passos abaixo. Quando tiver o Login e a API password em mãos, volte para a aba do formulário e cole nos campos correspondentes.

Atenção: API password ≠ senha do site A senha que você usa pra entrar no painel DataForSEO não funciona nas chamadas de API. É preciso copiar uma "API password" específica, gerada no painel.

Passos

  1. Crie ou entre na sua conta Acesse app.dataforseo.com/register (ou faça login se já tem conta). Confirme o e-mail.
  2. Adicione crédito (se ainda não tiver) DataForSEO funciona com pré-pago. O depósito mínimo costuma ser baixo. Sem saldo, as chamadas falham — mas a validação inicial usa um endpoint de custo zero.
  3. Abra a página de API Access No painel: app.dataforseo.com/api-access. É onde ficam Login e API password.
  4. Copie o "Login" Geralmente é o e-mail da sua conta. Cole no campo Login do formulário.
  5. Copie a "API password" Use o botão de copiar ao lado da API password. Cole no campo API password do formulário. Se não encontrar, há a opção "Generate new password" — gera uma nova, mas invalida a anterior.
  6. Volte para a outra aba e clique "Salvar credenciais" O SEO Brain valida com uma chamada gratuita ao endpoint /v3/appendix/user_data. Se passar, sua credencial fica salva localmente, com permissão de leitura só pra você.
Sobre os modos: use standard no dia a dia (mais barato). live é mais rápido mas custa mais. async é pra volume alto. offline pula chamadas reais à API — útil pra desenvolvimento ou pra cadastrar a credencial sem testar.
Esta aba é só leitura. Tudo acontece na aba do formulário.
