# Sample Project

Sample Project é uma marca de exemplo para validar o Companion em fluxos reais de edição, navegação e governança do cérebro do projeto.

A marca existe para testar uma experiência editorial clara, com links internos visíveis, metadados persistentes e decisões registradas sem depender de comandos de terminal.

Frase-marca: "Marca de exemplo para testes do Companion."

Use esta página como ponto de partida para entender o projeto antes de abrir conteúdos, revisar clusters ou conferir o histórico de decisões.

## Pilares do cérebro

### [[identity|Identidade]]

Aposto: Sample Project, marca de exemplo para testes do Companion.

- Valida edição de páginas autorais do brain.
- Mantém a frase-marca como texto renderizado, não como embed.
- Usa links internos reais para testar backlinks e navegação.
- Prioriza clareza editorial em vez de dashboards pesados no index.
- Registra decisões de fixture no [[log]].
- Sustenta testes de tags, callouts, mermaid e menções.

### [[voice|Tom de Voz]]

- Usar tom direto e operacional.
- Atribuir dados quando houver número, fonte externa ou decisão registrada.
- Preservar acentos em pt-BR.
- Evitar promessa promocional sem prova.
- Preferir frases curtas com sujeito, verbo e objeto.
- Manter instruções de teste separadas da prosa autoral.
- Usar wikilinks apenas para páginas reais do brain.
- Não transformar o index em painel técnico.
