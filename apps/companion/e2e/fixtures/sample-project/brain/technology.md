# Tecnologia

O site demonstrativo do Sample Project é um site editorial simples, representado por páginas estáticas e conteúdos publicados em Markdown. O objetivo técnico da fixture é manter uma base pequena para validar leitura, links e publicação de conteúdo sem assumir uma stack real de cliente.
